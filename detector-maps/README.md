# Detector channel maps

A graphical user interface (GUI) for visualizing the channel layout of a detector face. It is designed to run via github pages in order to be transportable, simple, and intuitive way to access detector's channel information and debugging tools.

| Detector | Map |
| --- | --- |
| Photek MAPMT (16 x 16) | [Photek Map](https://agcheyne.github.io/detector-ui/) |
| Photonis MA-PMT (8 x 8) | [Photonis Map](https://agcheyne.github.io/photonis-ui/) |
| HRPPD (32 x 32) | [HRPPD Map](https://agcheyne.github.io/hrppd-ui/) |

[Back to the homepage](https://agcheyne.github.io/)

## Installation
No installation needed. Simply visit the site.

## Features

- Visual representation of the detector's channel layout.
- Tools are available for:
  - Finding a pixel channel, and laser position (via click)
  - Look up for laser x,y position. Returns channel, and readout board.
  - Look up a channel position (all or in specific octants)
  - Adding a mask for laser scans, showing defined region of interest.
- Easy to extend and modify for future enhancements, and other detector layouts.

```
├── static

├── index.html                  # Photonis detector page

├── static
│   ├── detector-data.json      # HRPPD mapping/specs (generated by make_data.py)
├── make_data.py                # Builds detector-data.json from the mapping.c readout table
├── index.html                  # HRPPD detector page
detector-maps
├── README.md                   # This page
```
