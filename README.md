# agcheyne's homepage

Project pages and tools. Each project has its own page; new ones get added to the list below.

## Projects

### Detector channel maps

Interactive channel layouts of the photodetectors on our test bench: click a pixel for its readout channel and laser position, look up a laser position, highlight channels, draw a scan region.

- [Photek Map](https://agcheyne.github.io/detector-ui/)
- [Photonis Map](https://agcheyne.github.io/photonis-ui/)
- [HRPPD Map](https://agcheyne.github.io/hrppd-ui/)
- [About the maps (README)](detector-maps/)

## About this site

The site is built by GitHub Pages from this repository: this README is the homepage (`_config.yml` sets the title, description and theme), and each project lives in its own folder.

```
README.md                       # This homepage
_config.yml                     # Homepage config (title, description, theme)
detector-maps/README.md         # Detector maps documentation
detector-ui/                    # Photek map
photonis-ui/                    # Photonis map
hrppd-ui/                       # HRPPD map
```
